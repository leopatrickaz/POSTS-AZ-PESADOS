## Como adicionar um novo post

1. Copie `templates/template-legenda.md` para `posts/rascunhos/`.
2. Preencha a legenda, hashtags e briefing visual.
3. Adicione uma linha nesta tabela com data prevista e status `rascunho`.
4. Ao publicar, mova o arquivo para `posts/publicados/` e atualize o status para `publicado`.
